# Teleonline (Aplicación)

*[English version](README.en.md)*

Es una aplicación de reproducción multimedia para Android que centraliza el acceso a canales de televisión, mediante listas de reproducción en formato M3U8 y protocolos de streaming estándar (HLS/DASH).

Incorpora una guía electrónica de programación (EPG) con sistema de avisos, gestión de listas de favoritos y soporte para listas y guías EPG definidas por el propio usuario.

La aplicación cuenta con dos interfaces independientes, cada una optimizada para su plataforma: una para móvil y tablet, y otra para Android TV y Google TV con navegación completa mediante mando a distancia.

## Qué incluye

- Guía de programación con recordatorios
- Contenido "A la carta": programas emitidos en los últimos 7 días
- Contenido "bajo demanda" (VOD) de televisiones públicas
- Lista de favoritos editable
- Posibilidad de añadir listas personalizadas (M3U) y guia (EPG/XML)
- Reproductor con funcionalidades premium: calidad, audio, subtítulos, bloqueo de pantalla, apagado automático, segundo plano, gestos y zapping con mando
- Sincronización entre dispositivos
- Español, inglés, catalán, euskera y portugués

Nota: La aplicación se va mejorando con el paso del tiempo, esta lista de funcionalidades es orientativa.

## Instalación

### Móvil o tablet

1. Descarga el APK desde **[Releases](../../releases/latest)**
2. Ábrelo desde el móvil
3. Al no proceder de Google Play, Android mostrará un aviso de seguridad y pedirá permiso para instalar aplicaciones de origen desconocido. Es un comportamiento estándar del sistema para cualquier APK instalado fuera de la tienda oficial
4. Concede el permiso e instala

### Android TV o Fire TV

1. Instala **Downloader** desde la tienda de tu TV
2. Ábrela y pulsa el icono **#**
3. Introduce el código **4713504** y pulsa Cargar
4. Permite a Downloader instalar apps si lo pide
5. Instalar

Guía con capturas: [teleonline.app](https://teleonline.app)
